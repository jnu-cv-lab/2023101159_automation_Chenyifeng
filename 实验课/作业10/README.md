# ReadMe - 正弦位置编码 & RoPE 对比实验
## 项目简介
本项目基于 PyTorch 实现**传统正弦位置编码(Sinusoidal PE)**、**二维向量旋转**、**高维旋转位置编码(RoPE)**，并通过可视化图表+数值实验对比 `E+pos` 加法编码与 RoPE 旋转编码的差异，验证 RoPE 天然建模相对位置的特性，完成课程作业全部要求。

## 功能模块说明
### 1. 核心函数
1. **`sinusoidal_pe`**
    实现标准 Transformer 正弦位置编码，按奇偶维度分别计算 sin/cos 周期位置向量。
2. **`rotate_2d`**
    基础二维平面向量旋转变换，是高维 RoPE 的底层原理。
3. **`rope`**
    高维旋转位置编码，将特征维度两两分组，根据位置索引计算旋转角度并完成向量旋转。

### 2. 可视化与实验
代码执行后自动生成 4 张实验图表，对应作业验证需求：
1. **pe_heatmap.png**：正弦位置编码整体分布热力图
2. **add_vs_rope.png**：词嵌入+位置编码（加法）与 RoPE（旋转）两种位置注入方式对比
3. **rope_feature.png**：高维特征经过 RoPE 变换后的可视化结果
4. **rope_relative.png**：数值实验验证 RoPE 相对位置特性：**相同位置差，点积结果近似；不同位置差，点积结果差异明显**

## 实验结论（作业简答题）
### 1. Transformer 为什么需要位置编码？
Transformer 依赖自注意力机制，本身不具备时序感知能力，无法识别文本序列的先后顺序，因此必须**显式注入位置信息**。

### 2. 传统正弦位置编码如何生成？
针对序列位置与向量维度，采用指数衰减的频率，偶数维度使用 $\sin$ 函数、奇数维度使用 $\cos$ 函数，两两一组生成周期性位置向量。

### 3. E+pos 加法编码的缺陷
词嵌入特征与位置编码直接相加，**内容信息和位置信息相互混合、互相干扰**；且该方式为绝对位置编码，无法天然建模序列的相对位置关系。

### 4. RoPE 与加法编码的本质区别
RoPE 不使用加法融合，而是对特征向量做**几何旋转变换**，以维度分组旋转的形式嵌入位置信息。

### 5. RoPE 的作用对象
RoPE 仅作用于注意力机制中的 **Query(Q) 和 Key(K)** 向量，位置信息通过 Q、K 的交互融入注意力分数。

### 6. RoPE 相对位置原理
经过 RoPE 旋转后的 Q、K 做点积，最终结果**仅由两个 token 的位置差值（相对位置）决定**，与绝对位置无关，天然适配序列任务。

### 7. RoPE 相比 E+pos 更巧妙的原因
1. **信息解耦**：旋转变换实现内容与位置信息分离，不会相互污染；
2. **天然支持相对位置**：注意力分数依赖位置差，长文本泛化能力更强；
3. **轻量化**：无额外训练参数，计算效率高；
4. **表达能力更强**：几何变换的位置表征方式更贴合序列建模逻辑。
