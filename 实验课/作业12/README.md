## 项目简介
本项目基于 Python + OpenCV 实现**棋盘格相机标定**，完成手机相机内参、畸变系数求解、角点亚像素检测、重投影误差计算、图像去畸变全流程，适配课程计算机视觉相机标定实验作业。
使用 9×6 内角点棋盘格，16 张多角度实拍图像完成标定，输出完整标定参数、可视化图表、文本报告与可复用参数文件。

## 程序功能说明
1. **兼容中文路径**：封装图片读写函数，解决中文文件名读取失败问题
2. **批量角点检测**：自适应阈值+亮度归一化提升检测成功率，亚像素优化角点精度
3. **分辨率校验**：自动校验所有图片分辨率一致，防止标定报错
4. **相机标定求解**
   - 输出相机内参矩阵 K、5项畸变系数 D=[k1,k2,p1,p2,k3]
   - 计算 OpenCV 原生 RMS 重投影误差 + 每张图片平均重投影误差
5. **可视化输出**
   - 每张图片绘制棋盘格角点并保存
   - 原图/去畸变图对比图
   - 单张图片重投影误差柱状分布图
6. **结果持久化**
   - `.txt` 文本报告：可直接复制进实验报告
   - `.npz` 二进制文件：存储全部标定参数，可二次加载复用

## npz 参数文件使用方法
`.npz` 为 numpy 压缩参数文件，存储内参、畸变、误差、外参，不能直接双击打开，使用 Python 读取：
```python
import numpy as np
# 加载标定参数
data = np.load("/home/gevle/cv-course/标定结果/相机标定结果.npz")
# 查看内部存储字段
print(data.files)
# 提取参数
K = data["camera_matrix"]    # 相机内参
D = data["dist_coeffs"]      # 畸变系数
mean_err = data["reprojection_mean_error"]
print("相机内参矩阵：\n", K)
print("畸变参数：\n", D)
data.close()
```

## 常见问题与解决
1. **图片读取失败**
   检查路径是否为绝对路径，图片格式支持 jpg/png/tif，不要使用微信压缩图片。
2. **角点检测失败**
   图片模糊、反光、棋盘格裁切、角度过大；重新拍摄保证棋盘完整、光线均匀。
3. **去畸变前后视觉差别很小**
   手机主摄畸变微弱，畸变主要集中画面四角；放大边缘直线可观察矫正效果。
4. **有效图片不足警告**
   至少保证10张以上可检测图片，推荐15~20张多角度素材。
